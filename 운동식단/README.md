## 🔁 사용 방법

1. 매주 같은 요일·시간에 **체중 측정** → `기록.md`에 기록
2. 운동한 날 `운동루틴.md`의 A/B/C 순서대로 진행
3. 식단은 칼로리·단백질만 맞추면 음식 종류는 자유
4. 2주마다 평균 체중 변화를 확인하고 섭취량 조정
   - 2주간 거의 안 빠짐 → 하루 -150kcal
   - 2주간 1.5kg 이상 빠짐 → 하루 +150kcal (너무 빠름)
