# 사업·성공 파트너 어드바이저

내 사업과 성공을 위해 **방향을 잡아주고, 사각지대를 찔러주고, 지식·노하우를 축적**해 더 높은 부의 사다리에 올라타도록 돕는 AI 파트너 시스템.

한 번의 대화로 흩어지지 않도록, 모든 것을 이 저장소에 **누적되는 자산**으로 남긴다.

## 구성

```
business-advisor/
├─ PERSONA.md              ← AI에게 부여할 시스템 프롬프트(역할·원칙·운영 루틴)
├─ knowledge/
│  ├─ books.md             ← 경영·경제 추천 도서 + 핵심 요약(계속 추가)
│  ├─ frameworks.md        ← 의사결정·사고 프레임워크 모음
│  └─ playbook.md          ← '부의 사다리' 전략 플레이북
└─ journal/
   ├─ profile.md           ← 내 프로필·목표·제약(개인화 메모리)
   ├─ decisions.md         ← 중요한 의사결정 로그
   └─ insights.md          ← 쌓아가는 인사이트·노하우
```

## 사용법

1. **새 대화 시작 시**: `PERSONA.md` 전체를 AI에게 붙여넣어 역할을 부여한다.
2. **맥락 제공**: `journal/profile.md`와 최근 `journal/decisions.md`·`journal/insights.md`를 함께 첨부한다.
3. **대화 후**: 남길 가치가 있는 결정·인사이트는 해당 파일 템플릿에 맞춰 기록한다. (AI에게 "이번 대화 정리해서 journal에 추가할 항목 만들어줘"라고 요청)
4. **주기적 리뷰**: 분기마다 `decisions.md`를 다시 읽고 "그때의 판단이 맞았나"를 복기한다. 복기야말로 노하우가 복리로 쌓이는 지점이다.

## 운영 원칙 (한 줄 요약)

> 아첨하지 않고, 역발상을 던지고, 항상 다음 행동으로 끝낸다. 그리고 모든 것을 기록한다.

자세한 가치관과 행동 규칙은 [`PERSONA.md`](./PERSONA.md) 참고.
