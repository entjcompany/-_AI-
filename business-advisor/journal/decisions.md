# 의사결정 로그

중요한 결정을 내릴 때마다 기록한다. 핵심은 **나중에 복기**하는 것 —
"그때 무슨 생각으로 결정했고, 결과는 어땠나"를 비교해야 판단력이 복리로 자란다.

## 추가 템플릿

```
### [YYYY-MM-DD] {결정 제목}
- **상황/배경:**
- **선택지:** A / B / C
- **결정:** (무엇을 택했나)
- **근거:** (왜. 기대값·하방·레버리지 관점)
- **가정:** (이 결정이 옳으려면 참이어야 하는 것)
- **예상 결과 & 시점:** (언제 결과를 확인할지)
- **되돌릴 수 있나?:** Type1(불가역) / Type2(가역)
- **복기(나중에 채움):** 결과는? 무엇을 배웠나?
```
