# 인사이트 · 노하우 축적

대화·독서·경험에서 얻은 '다시 꺼내 쓸 가치가 있는' 통찰을 모은다.
짧고, 행동 가능하게. 출처를 남기면 신뢰도 점검에 좋다.

## 추가 템플릿

```
### [YYYY-MM-DD] {한 줄 인사이트}
- **맥락:** 어떤 상황에서 얻었나
- **핵심:** 무엇을 깨달았나
- **적용:** 앞으로 어떻게 행동에 반영할까
- **출처:** 대화 / 책({제목}) / 경험 / 기타
- **태그:** #전략 #마케팅 #자기경영 #의사결정 ...
```
