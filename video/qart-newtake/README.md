# 큐아트제작소 쇼츠 — "브랜드 설정 온도"

레퍼런스 영상(https://youtu.be/3atCau1bRj8, 화이트보드 졸라맨 설명형)의 **구조만** 가져와 큐아트제작소 메시지로 새로 만든 9:16 쇼츠입니다.

- 결과물: `qart_newtake.mp4` (1080×1920, 24fps, 87초, 자막 내장, 무음 트랙)
- 자막: `qart_newtake.srt` (내레이션 원고와 동일, 녹음·TTS 싱크용)
- 소스: `scene.html` (장면·자막 정의), `render.js` (프레임 캡처 → ffmpeg)

## 3. 다시 렌더링하기

```bash
node render.js --stills 7,34,60      # 특정 시점 미리보기 PNG
node render.js qart_newtake.mp4 24   # 전체 렌더 (약 2분)
```

문구는 `scene.html`의 `CAP`(자막)와 각 `add(...)` 장면에서 고치면 됩니다. 업종별(병원/커머스/B2G) 버전은 훅 4문장과 CTA만 바꿔 재사용할 수 있습니다.

## 4. 남은 작업

- **내레이션 음성 없음**: 이 환경에서는 TTS 서비스에 접근할 수 없어 무음 트랙으로 렌더했습니다. `qart_newtake.srt` 기준으로 녹음하거나 TTS를 입혀 `ffmpeg -i qart_newtake.mp4 -i voice.mp3 -map 0:v -map 1:a -c:v copy -shortest out.mp4`로 합치면 됩니다.
- BGM은 저작권 확인된 음원으로 별도 삽입이 필요합니다.
